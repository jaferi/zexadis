# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

For a vulnerability affecting Zexadis, please use GitHub's private security reporting mechanism or contact the project maintainers privately.

Please include:

* A description of the vulnerability
* Steps to reproduce the issue
* Affected versions or commits
* Potential impact
* Any suggested mitigation, if available

## Supported Versions

Zexadis is currently under active development. Security support is provided for the latest development version.

Because the project is pre-release, APIs and security characteristics may change as the architecture evolves.

## Scope

Security reports are particularly relevant to:

* Memory safety
* Remote code execution
* Authentication or authorization bypasses
* Denial-of-service vulnerabilities
* Protocol parsing vulnerabilities
* Unexpected data exposure
* Container or deployment security issues
